## 1. Service description (paste into Partner Center — English)

WinWinBack is a cashback service built on the TikTok Shop Open Platform (Affiliate
Creator API).

Integration & data flow:
1. **Connect** — The business authorizes a TikTok Shop Affiliate Creator account via
   OAuth (scopes: `creator.affiliate.link.write`, `creator.affiliate_collaboration.read`).
   Tokens are stored server-side and auto-refreshed.
2. **Product data** — A user pastes a TikTok Shop product link. Our backend resolves the
   **Product ID (starts with 17...)** and calls the **Generate Affiliate Sharing Links**
   API (`/affiliate_creator/202505/.../generate_batch`) to create a tracked link.
3. **Order data sync** — When a buyer purchases via the link, our backend calls the
   **Affiliate Orders Search** API (`/affiliate_creator/202410/orders/search`) to
   synchronize the affiliate order. Each synced record carries the real **Order ID
   (starts with 57/58...)**, Product ID (17...), product name, price and status.
4. **Cashback** — When an order reaches a completed/settled status, cashback is credited
   to the user's in-app wallet; the user can request a withdrawal.

Where reviewers can see it: **Admin → Integrations** page shows the connected creator
(open_id, granted scopes, token expiry) and a **"Sync orders"** button that pulls live
orders from TikTok Shop and renders a table of Order IDs (57/58...) and Product IDs (17...).
